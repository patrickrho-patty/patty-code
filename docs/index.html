Install
설치

Up and running in one line.한 줄이면 바로 시작됩니다.

The npm package pulls the prebuilt native binary for your platform — no Node runtime needed to run it.npm 패키지가 플랫폼에 맞는 사전 빌드 네이티브 바이너리를 내려받습니다. 실행에 Node 런타임은 필요하지 않습니다.

$ npm i -g patty-code
$ patcode setup        # config wizard → ./patty.toml
$ patcode         # or: patcode run \"implement the TODOs\"

Any OS · macOS, Linux, Windows × amd64/arm64.모든 주요 OS · macOS, Linux, Windows × amd64/arm64.

$ brew install patty-io/patty-code

Features
기능

Built for long, cheap, controllable sessions.길고, 저렴하고, 통제 가능한 세션을 위해 설계되었습니다.

01

Cache-first loop

캐시 우선 루프

Append-only history aligned to a cache-stable prefix. Long sessions stay cheap and predictable.

append-only 기록과 cache-stable prefix 구조로 긴 세션도 저렴하고 예측 가능하게 유지합니다.

02

Single Go binary

단일 Go 바이너리

CGO-free, cross-compiled for darwin/linux/windows × amd64/arm64. No Node runtime.

CGO 없이 darwin/linux/windows × amd64/arm64로 교차 빌드됩니다. 실행에 Node 런타임이 필요하지 않습니다.

03

MCP first-class

stdio, SSE, streamable HTTP. External servers merge their tools into one registry under a prefix.

stdio, SSE, streamable HTTP를 지원합니다. 외부 서버의 도구는 prefix 아래 하나의 registry로 합쳐집니다.

04

Plan mode + sandbox

계획 모드 + 샌드박스

/plan asks the model to plan first; Permissions and the workspace sandbox still govern every tool call.

/plan은 먼저 계획을 세우게 하고, 모든 도구 호출에는 여전히 권한과 워크스페이스 샌드박스가 적용됩니다.

05

Subagents & skills

서브에이전트와 스킬

explore / research / review / security-review agents, plus Markdown skill scripts with isolated tools.

explore / research / review / security-review 에이전트와 격리된 도구를 쓰는 Markdown 스킬 스크립트를 제공합니다.

06

Terminal-native

터미널 네이티브

Not another IDE plugin. git diff handles diffs, ls handles trees — the terminal is the workspace.

또 하나의 IDE 플러그인이 아닙니다. git diff가 diff를, ls가 트리를 맡고, 터미널이 곧 워크스페이스가 됩니다.

Why Patty Code
왜 Patty Code인가

Korean-first where it actually matters.정말 중요한 지점에서 한국어 퍼스트.

Most coding agents were built for someone else first. Patty Code is designed around Korean input, long-session control, and local autonomy you can actually inspect and trust.대부분의 코딩 에이전트는 다른 사용자를 먼저 기준으로 설계되었습니다. Patty Code는 한국어 입력, 긴 세션 통제, 직접 확인하고 믿을 수 있는 로컬 자율 실행을 중심에 둡니다.
