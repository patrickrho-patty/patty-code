Patty Code's legacy IM bot integrations are not part of the supported product
surface in this repository.

If you find historical bot-related configuration, screenshots, or older release
notes, treat them as legacy material rather than current guidance.

For supported ways to use Patty Code today, use:

- the CLI / TUI
- the desktop app
- the browser/serve UI
- ACP editor integration

See the main [Guide](./GUIDE.md) for the current supported workflows.
