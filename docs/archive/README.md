# Archived documentation

These files are retained for provenance only. They are not part of the
runtime documentation corpus, are not linked from the product guide, and are
not promises about the current Patty Code product.

- `internal/` — superseded program and release-planning material
- `assets/design-previews/` — historical desktop layout references
- `assets/logo-experiments/` — unused animated logo experiments

New user-facing documentation belongs at `docs/` and should be linked from
[`docs/README.md`](../README.md). Generated protocol material belongs beside
the source generator and must not be hand-edited.
